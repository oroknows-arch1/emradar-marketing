# Editorial transformation and campaign cost receipts

Open-route scouting emits internal briefs only. `editorial_intelligence` checks source bindings, then invokes the existing Harness with the full Editorial Copy System, product voice, destination requirements and source uncertainty. No campaign-specific copy or language shortcut exists. A missing executor blocks generation. The verifier must return `editorial_checks` for factual entailment, uncertainty preservation, destination fit and originality; all must pass. The result carries subject, body, language, original signal state, evidence refs, grounded claim spans and qualification spans for each source uncertainty. These mechanical checks supplement provider verification; they do not prove prose quality by themselves.

Verified results are cached against the complete context and contract. Owner rejection invalidates the associated cache and permanently blocks approval of that proposal. A repeated rejected result cannot re-enter review. `/PUBLICATION_REVIEW` accepts an explicit `decision: REJECTED`, exact proposal/hash and reason. It never sends anything for that decision. Run input `stop_at: PUBLICATION_REVIEW` forces review even when a prior matching approval exists.

Each campaign and feedback execution starts a durable `campaign_cost:<run_id>` record. Every reserved worker, delivery and paid observation action records its intent before dispatch and settles its billing separately. Failed calls retain billing or an explicit UNKNOWN reason. Run finalization consolidates categories after the graph loop, including review stops, source rejection, worker failure and step limits. An interrupted run retains its unfinished receipt and uncertain reservations. Retry attempts retain their individual provider billing. Historical source acquisition and maintenance-session costs are outside a new graph run's scope and are not silently reported as zero.

Authenticated `GET /cost-receipts?run_id=...` returns a receipt. `GET /cost-receipts?campaign_id=...` returns durable run history and its consolidated AUD total. Missing history or any unknown amount makes the consolidated total UNKNOWN. No index truncation applies. Actual, verified calculated, zero and unknown costs stay distinct. Calculated token prices require verified metadata and a verified AUD conversion; calculated reporting does not relax the existing actual-billing spending gate.

The AUD 5 campaign and AUD 50 Australia/Sydney calendar-month limits remain in the existing SpendEnvelope. Reconciled monthly billing and provider-enforced quotes remain prerequisites for paid work. Production requires the existing approved Harness transport credentials, a trusted creation budget and reconciled billing; there is no credential or billing bypass.
